# Safar Squad Tours & Travel - Standalone Website Project

This is a complete, turnkey Next.js standalone website project created for **Safar Squad Tours & Travel** (Where Every Journey Feels First Class).

## How to Run in a New Project

1. Unzip this package to your desired project directory.
2. Open terminal in the directory and install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser. The homepage `/` immediately displays **Safar Squad Tours & Travel**'s personal branding website!

## How to Deploy to Production (Vercel / Netlify)

- Push this repository to GitHub.
- Connect your GitHub repository to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
- Click Deploy! Zero configuration required.
